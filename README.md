# Бурмалда — GitHub Pages

Готовая публичная версия. Доступен «Район»; «Село» и мотоблок закрыты.
Панели разработчика здесь нет. Ишак, турбоишак и сохранение прогресса работают.

## Как опубликовать

1. Создайте репозиторий на GitHub (для бесплатного GitHub Pages — публичный).
2. Загрузите **содержимое этой папки** в корень репозитория:
   `index.html`, папку `assets`, `.nojekyll`, `MODEL-SOURCES.txt` и этот README.
   Если используете ZIP, сначала распакуйте его: архив сам по себе сайтом не станет.
   Не загружайте рабочую папку проекта `work` или HTML для разработки.
3. В репозитории откройте **Settings → Pages → Deploy from a branch**.
   Выберите ветку **main** и папку **/(root)**, затем **Save**.
4. Когда публикация закончится, ссылка появится в **Settings → Pages → Visit site**.
   Обычно адрес имеет вид `https://ВАШ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/`.

Если сайт размещается в подпапке репозитория, относительные пути к ресурсам
продолжают работать. Для следующих обновлений заменяйте файлы этой сборки.
Для публикации через `/docs` поместите всё содержимое этой папки в `/docs`
и выберите `/docs` в настройках Pages.

Музыка включается после нажатия «Погнали». Все ресурсы находятся в `assets`.
Прогресс сохраняется отдельно от версии разработчика и привязан к браузеру/адресу.
Локальная версия для запуска двойным щелчком — `outputs/Бурмалда.html`
в исходном рабочем проекте. Она не входит в публичный архив.

Официальные инструкции GitHub:
https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

Авторы и условия использования моделей указаны в MODEL-SOURCES.txt и меню игры.
